# `prototype/` — the SEG prototype

The third stage of the [maturity pipeline](../notes/seg_pipeline_model.md): the SEG
prototype receives new additions, but this is **not yet true software engineering** —
it favours quick results to learn through feedback before design elements harden into
[`development/`](../development/).

| Path | What lives there |
|---|---|
| [`graph-construction/`](graph-construction/) | The **original SEG prototype** — graph construction, coverage, and suspect-propagation workflows (its own README + `NOTES.md`, schemas, sample stores). |
| [`notes/`](notes/) | Stage notes, including the prototype agent brief. |
| [`design/`](design/) | Reserved for prototype-stage design (currently empty). |

This stage does **not** use the Phase B worktree topology — that belongs to
[`development/`](../development/).
