# `funnel/` — idea exploration

The first stage of the [maturity pipeline](../notes/seg_pipeline_model.md): raw,
unstructured idea capture before anything is committed to. No constraints, no design
obligations — just somewhere to park candidate directions.

**Intentionally empty at this stage.** Seeds are added here when a new direction is
worth exploring; once an idea earns deeper grounding it graduates to
[`research/`](../research/).
