# `notes/` — cross-cutting record

Material that spans the whole [maturity pipeline](seg_pipeline_model.md) and does not
belong to any single stage.

| File / path | What it is |
|---|---|
| [`decision_log_index.md`](decision_log_index.md) | Master index of decisions DEC-001…028 (DEC-id → stage slice → summary), with supersession and AC-footprint links. The stage slices live in `development/notes/` and `research/notes/`. |
| [`seg_pipeline_model.md`](seg_pipeline_model.md) | The four-stage maturity model and the canonical migration record (target layout, conventions, apply log). |
| [`seg_glossary.md`](seg_glossary.md) | Terms. |
| [`ppt_overview_brief.md`](ppt_overview_brief.md) | Overview presentation brief. |
| [`sessions/`](sessions/) | Session history — the [`SESSIONS.md`](sessions/SESSIONS.md) sidebar, distilled per-topic notes, and [`archive/`](sessions/archive/) for spent artifacts. |

Decisions are the **record of record**; this folder indexes them but the citeable
*why* lives in the slices linked from the index.
